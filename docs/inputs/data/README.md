# Data files

## Production recommendation data

`house_dark_500_films.json` is the build-friendly source of truth for the finite Trust Us recommendation universe.

`house_dark_500_films.xlsx` is the original curated workbook.

`house_dark_500_films.csv` is provided for simple imports.

`house_dark_theme_map.json` contains the 20 intent-led theme definitions.

`house_dark_500_validation.json` records handover validation.

## Prototype data

`fixtures.json` is for UI/state demonstrations only.

Do not use the small fixture list as the production recommendation database.

## State and motion

`product-state-machine.json` documents product states.

`motion-tokens.json` documents timing tokens.
