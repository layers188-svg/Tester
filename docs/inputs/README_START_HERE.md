# House Dark Claude Code handover

This folder is designed to be dropped into the House Dark repository and handed directly to Claude Code.

## Start here

1. Put this folder in the repository root, or copy its contents into a `/handover/house-dark/` folder.
2. Tell Claude Code to read `CLAUDE.md` and complete the build autonomously.
3. Give Claude Code access to the actual House Dark repository. This package contains product, design, motion, fixtures and reference assets, but it is not a replacement for the production source repository.
4. The prototype HTML is a behavioural reference. It is deliberately not treated as production code.

## Important

The latest conversation changed several earlier product assumptions. The final brief in this package wins where older documents differ.

Most importantly:

- Tonight must never reveal the title before the No Trailer finishes.
- Search must not become a catalogue. The member gives House Dark a theme and House Dark chooses one film.
- The supplied 500-film library is the finite recommendation universe for Trust Us. It replaces any endless/open-ended recommendation repository.
- The six sample videos already in the production repository are existing assets. Inventory and use them; do not ask for re-upload unless they are genuinely missing.
- V15 is the preferred visual prototype direction. The later V16 control experiment is not the visual target.
- The Room contains Your Review, Your Circle and The House.
- Circle supports both receiving and sending a recommendation under seal.
- Motion is a product system, not decoration.
